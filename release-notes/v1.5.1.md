# PokeSurvivor Plus 1.5.1

## ⬇ Install

**Chromium browsers (recommended):** [add PokeSurvivor Plus from the Chrome Web Store](https://chromewebstore.google.com/detail/pokesurvivor-plus/deobgjkejfjknofekpfccfbghgbhiidn) (updates install automatically; works in Chrome, Brave, Edge and Opera).

**Firefox and Zen:** download **`pokesurvivor-plus-1.5.1.xpi`** below (under **Assets**). In Firefox or Zen, open `about:debugging`, click **This Firefox**, click **Load Temporary Add-on** and pick the downloaded file. Needs Firefox 128 or newer (and the same base version for your Zen build). A temporary add-on is removed when the browser closes — it loads again the same way each session until the signed listing on [addons.mozilla.org](https://addons.mozilla.org/) is up.

**Chromium manual install:** download **`pokesurvivor-plus-1.5.1.zip`** below (under **Assets**), extract it, open `chrome://extensions` (or `edge://`, `brave://`, `opera://extensions`), turn on **Developer mode**, click **Load unpacked** and select the **`pokesurvivor-plus-1.5.1`** folder. Don't keep both versions on at once.

Desktop browsers only for now: Chrome-family and Firefox-family. Full guide: [INSTALL.md](https://github.com/PokeSurvivorPlus/PokeSurvivorPlus/blob/main/INSTALL.md).

## ✨ What's new

- **Firefox support.** The same extension now installs and runs in Firefox and Firefox-based browsers like Zen — same features, same everything you see in Chrome: the redesigned HUD, damage meter, minimap, controller support, tier list, alerts and the rest. There is still a single build: Chrome runs it as a service worker and Firefox as an event page, and the extension picks each browser's interface on its own, so there is nothing to configure and nothing to maintain twice.
- The release now comes as both a Chrome `.zip` and a Firefox `.xpi`, built from the same files.

Requires Firefox 128 or newer. Zen inherits Firefox 128+ too, so today's builds are fine.
