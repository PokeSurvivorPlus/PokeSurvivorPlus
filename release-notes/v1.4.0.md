# PokeSurvivor Plus 1.4.0

## ⬇ Install

**Recommended:** [add PokeSurvivor Plus from the Chrome Web Store](https://chromewebstore.google.com/detail/pokesurvivor-plus/deobgjkejfjknofekpfccfbghgbhiidn) (updates install automatically; works in Chrome, Brave, Edge and Opera).

**Manual install:** download **`pokesurvivor-plus-1.4.0.zip`** below (under **Assets**), extract it, open `chrome://extensions` (or `edge://`, `brave://`, `opera://extensions`), turn on **Developer mode**, click **Load unpacked** and select the **`pokesurvivor-plus-1.4.0`** folder. Don't keep both versions on at once.

Chromium-based desktop browsers only for now. Full guide: [INSTALL.md](https://github.com/PokeSurvivorPlus/PokeSurvivorPlus/blob/main/INSTALL.md).

## ✨ Since 1.0

- **Rooms of up to 8 players**, with four new player colours and gentler enemy scaling past 4. Runs of 5–8 never go on the leaderboard.
- **Create room** with a short **6-digit code**, **room codes and join links** anyone can use (great for streams), a **Join** button and live status on the friends list, and invites from anyone in the room. The host can **Kick** players; full rooms say so.
- **Co-op runs:** change your level-up card until everyone has chosen, pick bonds at the same time, and open chests / revive faster together.
- **Spanish:** PokeSurvivor Plus follows the game's language.
- **Hover any move** to see what it does (Upgrades and level-up cards), altar powers explain themselves, colour blind mode can apply to the UI only, a red **low-health vignette**, and shiny Pokémon **twinkle**.
- Many fixes: the National Pokédex, the mouse wheel on the Pokémon screen, bosses stuck after rifts, the controller cursor in Upgrades, and more.
