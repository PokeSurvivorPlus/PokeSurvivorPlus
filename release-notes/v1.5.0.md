# PokeSurvivor Plus 1.5.0

## ⬇ Install

**Recommended:** [add PokeSurvivor Plus from the Chrome Web Store](https://chromewebstore.google.com/detail/pokesurvivor-plus/deobgjkejfjknofekpfccfbghgbhiidn) (updates install automatically; works in Chrome, Brave, Edge and Opera).

**Manual install:** download **`pokesurvivor-plus-1.5.0.zip`** below (under **Assets**), extract it, open `chrome://extensions` (or `edge://`, `brave://`, `opera://extensions`), turn on **Developer mode**, click **Load unpacked** and select the **`pokesurvivor-plus-1.5.0`** folder. Don't keep both versions on at once.

Chromium-based desktop browsers only for now. Full guide: [INSTALL.md](https://github.com/PokeSurvivorPlus/PokeSurvivorPlus/blob/main/INSTALL.md).

## ✨ What's new

- **Works with the game's 18 and 19 October updates.** Where the game now does something PokeSurvivor Plus already did, you get one of each: the game's search and filters with Plus's sorting, one shared set of favourites (saved with your account), and Plus's controller support (the game's Manual aim works with your right stick).
- **Game updates no longer end your run:** you're told an update is out and that the run won't go on the leaderboard; the game updates back at the menu.
- **Level-up cards show what a move does** right on the card.
- **Share card** on the game-over screen.
- The game's new languages are in Settings → Accessibility → Language; HUD size goes down to 0.5×; shiny twinkles are easier to spot; 1 second of flashing safety after a rift; profiles show favourites as in-game sprites.
- Fixes: the Play button flashing “Enter the dungeon”, the endless pause menu on a controller, the new Starting move upgrade card, and the game's title line showing twice.
